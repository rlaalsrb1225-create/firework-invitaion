# firework-invitaion

Afterglow 불꽃놀이 인터랙션을 Next.js App Router로 옮긴 결혼식 초대 사이트 프로젝트입니다.

## 로컬 실행

Node.js 20.9 이상이 필요합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 확인과 배포

```sh
npm run build
vercel deploy --prod
```

이 폴더는 별도 Vercel 프로젝트 `firework-invitaion`에 연결되어 있습니다. 로컬 연결 정보와 환경 변수는 Git에 포함하지 않습니다.

배포 주소: https://firework-invitaion.vercel.app/
